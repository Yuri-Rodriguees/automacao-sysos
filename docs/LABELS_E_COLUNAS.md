# Mapeamento de Labels e Colunas 🏷️

Tabela de referência das labels e colunas utilizadas no GitHub Projects para espelhar o fluxo do SysOS.

---

## 1. Labels de Prioridade

| Label | Cor (HEX) | Descrição |
| :--- | :--- | :--- |
| `prioridade::baixa` | `#3498DB` | Demandas sem impacto crítico imediato |
| `prioridade::media` | `#F1C40F` | Demandas regulares de desenvolvimento |
| `prioridade::alta` | `#E67E22` | Demandas com prazo ou impacto operacional alto |
| `prioridade::critica` | `#E74C3C` | Erros em produção ou itens impreteríveis |

---

## 2. Labels de Tipo

| Label | Cor (HEX) | Descrição |
| :--- | :--- | :--- |
| `tipo::funcionalidade` | `#2ECC71` | Nova tela, novo módulo ou criação |
| `tipo::melhoria` | `#9B59B6` | Otimização ou evolução de recurso existente |
| `tipo::correcao` | `#E67E22` | Correção de bug ou falha identificada |
| `tipo::tarefa-tecnica` | `#1ABC9C` | Ajustes de banco, procedures, infra ou refatoração |
